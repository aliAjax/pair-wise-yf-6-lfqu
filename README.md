# 维修责任判定台

端口规划：`5114`

```bash
npm install
npm run dev
```

出租房维修的责任账闭环：

- 报修先记为**待判定**；完工（状态改为「已完成」）后，根据现场说明和照片判定为房东承担、租客承担或双方分摊。
- 判给租客的费用先在**押金里预留**，双方都在卡片上确认后才转为**押金扣减**；判给房东的直接计入**房东支出**。
- **改判**会先把原金额从押金/房东支出里退回，再按新结果重算，同一笔维修不会两边都算。
- 列表按**待判定 / 待确认 / 已结清**分栏，底部「责任账流水」记录每笔入账、扣减与退回，可逐条复核。

代码按职责拆为三个业务文件：

- `src/liability.js` —— 判定规则：费用拆分、押金预留/扣减、改判冲正、账目汇总。
- `src/migration.js` —— 数据升级：旧版本地事项与费用原样可读，自动补全责任账结构。
- `src/main.js` —— 页面交互：渲染与事件绑定。

数据仍保存在 localStorage，无后端、无新增依赖。
