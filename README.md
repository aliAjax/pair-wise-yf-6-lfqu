# 出租房维修责任账

端口规划：`5114`

```bash
npm install
npm run dev
```

在原有本地维修事项（localStorage 保存、照片链接、状态跟踪）之上，把维修费用补成可复核的责任账：

- 报修先记「待判定」，完工后根据现场说明和照片判定为房东承担、租客承担或双方分摊。
- 判给租客的费用先在押金里预留，双方确认后才扣减；判给房东的计入房东支出。
- 改判先把原金额退回（预留退回 / 扣减退回 / 支出冲回），再按新结果重算，同一笔维修只按当前判定记一次。
- 列表按待判定、待确认、已结清分开查看，另有责任账流水可逐笔复核。

代码拆分：`src/liability.js` 判定规则，`src/storage.js` 数据升级（旧数据保留位置、费用、状态、照片、备注），`src/main.js` 页面交互。无后端、无新增依赖。
